关于 CalmCore What is CalmCore?

CalmCore 是面向实时业务与分析的分布式 HTAP 数据库，依托 Partition Owner 模型、CubeFS 共享存储与 Chitchat Gossip 协调，实现“单写入者 + 全节点读取”的一致性语义，以及秒级的算力扩缩容。GraphQL DDL 负责模式治理，MySQL 与 Elasticsearch 协议承担数据写入与检索，配合 Arrow Flight 联邦查询让计算层保持完全无状态。 CalmCore is a distributed HTAP database built on the Partition Owner model, CubeFS shared storage, and Chitchat gossip coordination. Single-writer semantics with universal readers keep elasticity snappy while GraphQL governs schema, MySQL/Elasticsearch handle ingestion and lookup, and Arrow Flight orchestrates stateless federated analytics.

Partition Owner

单写入者 · 精准所有权 Single Writer · Precise Ownership

每个分区由唯一 Owner 执行 `Engine::insert_batch`，Gossip 自动探测所有权变更，杜绝双写与脑裂。 A single owner runs `Engine::insert_batch` per partition while gossip-driven ownership changes prevent split-brain writes.

Shared Storage

CubeFS + 无状态算力 CubeFS + Stateless Compute

所有节点通过 CubeFS/S3 读取统一数据湖，热数据、列式段与索引统一存储，节点可随用随起。 Every node reads the same CubeFS/S3 lake for hot segments, columnar files, and indexes so compute capacity is just spin-up time.

Multi-Protocol

GraphQL + MySQL + ES GraphQL + MySQL + ES

GraphQL 负责建模，MySQL 与 Elasticsearch 负责写入和检索，Arrow Flight 联邦执行查询语句。 GraphQL drives DDL while MySQL and Elasticsearch endpoints ingest and query data, and Arrow Flight pushes distributed scans.

HTAP Engine

Rust + DataFusion 51 Rust-native HTAP

Rust 引擎同时提供事务写入、批量分析、全文检索与向量算子，一份数据覆盖 OLTP/OLAP。 The Rust engine blends transactional inserts, analytical scans, full-text, and vector operators so one dataset powers OLTP and OLAP.
