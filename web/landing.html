什么是 CalmCore? (What is CalmCore?)

CalmCore 是一个为极致扩展性而生的数据库系统。通过将计算与存储完全解耦，CalmCore 运行在 CubeFS 分布式文件系统之上， 利用 Gossip 协议 实现集群节点的自愈与发现。无论是海量数据的实时分析，还是高并发的事务处理，CalmCore 都能通过横向扩展计算节点轻松应对。

(CalmCore is a database system born for extreme scalability. By completely decoupling computing and storage, CalmCore runs on top of the CubeFS distributed file system and uses the Gossip protocol to achieve self-healing and discovery of cluster nodes. Whether it's real-time analysis of massive data or high-concurrency transaction processing, CalmCore can easily handle it by horizontally scaling compute nodes.)

核心特性 (Core Features)

🚀

高性能 (High Performance)

基于 Rust 构建，提供内存安全和极致的执行效率，支持高吞吐量写入和低延迟查询。(Built on Rust, it provides memory safety and ultimate execution efficiency, supporting high-throughput writes and low-latency queries.)

Cloud Native
🌐

存算分离架构 (Separation of compute and storage)

底层基于 CubeFS 共享存储，计算节点完全无状态，支持秒级横向扩缩容。(Based on CubeFS shared storage, compute nodes are completely stateless and support horizontal scaling in seconds.)

Decentralized
🔌

Gossip 集群协调 (Gossip Cluster Coordination)

采用去中心化的 Gossip 协议进行成员发现与状态同步，消除单点故障，确保集群高可用。(It adopts a decentralized Gossip protocol for member discovery and status synchronization, eliminating single points of failure and ensuring high cluster availability.)

📊

HTAP 能力 (HTAP Capability)

同时支持快速的事务处理和复杂的分析查询，满足混合工作负载的需求。(Simultaneously supports fast transaction processing and complex analytical queries to meet the needs of mixed workloads.)

🛡️

高级分区 (Advanced Partitioning)

支持按哈希、范围和时间等多种策略进行数据分区，优化查询性能和数据管理。(Supports data partitioning by multiple strategies such as hash, range, and time to optimize query performance and data management.)

🔍

强大的全文搜索 (Powerful Full-text Search)

内置高效的倒排索引，提供丰富的全文搜索功能，如下推、模糊查询和短语匹配。(Built-in efficient inverted index provides rich full-text search functions, such as pushdown, fuzzy query, and phrase matching.)

🧬

向量检索 (Vector Search)

支持高维向量索引与相似度检索，助力 AI 与大模型应用，实现毫秒级语义搜索。(Supports high-dimensional vector indexing and similarity retrieval, empowering AI and large model applications to achieve millisecond-level semantic search.)

🕸️

图搜索 (Graph Search)

内置图数据处理能力，支持复杂的关联查询与路径分析，探索数据间的深层联系。(Built-in graph data processing capabilities, supporting complex association queries and path analysis to explore the deep connections between data.)
